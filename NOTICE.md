About STIG Viewer 3 (SV3)

This project is tooling that extracts and launches DISA's STIG Viewer 3.
STIG Viewer 3 is a U.S. Government (DISA) product. This repository does NOT
contain, vendor, redistribute, or modify SV3's source code or binaries — the
setup script downloads SV3 directly from the DISA CDN at run time and
extracts it locally on the user's machine. All rights to STIG Viewer 3
belong to DISA / the U.S. Government. The Apache-2.0 license above applies
only to the sv3-runner tooling (the scripts and configuration in this
repository), not to STIG Viewer 3 itself.
